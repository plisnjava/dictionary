# Словник

Особистий словник термінів з навчання. Працює як програма на iPhone: її можна додати на початковий екран, і вона відкривається без інтернету.

**Дані зберігаються лише на тому пристрої, де ви ними користуєтесь.** На сервер нічого не надсилається. Тому інші люди, які відкриють це посилання, побачать порожній словник.

## Запуск на GitHub Pages

1. Settings → Pages → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → Save.
2. Приблизно за хвилину сайт буде доступний на `https://morechancenow.github.io/slovnyk/`.

## Встановлення на iPhone

1. Відкрийте посилання в **Safari**.
2. Натисніть «Поділитися» → «На початковий екран» → «Додати».
3. Далі відкривайте словник тільки через іконку. У програми з початкового екрана сховище окреме від Safari.

## Резервна копія

- **Зберегти копію**: відкриває меню «Поділитися», де можна вибрати «Зберегти у Файли» (iCloud Drive). Файл має назву `slovnyk-РРРР-ММ-ДД.json`.
- **Відновити з файлу**: додає записи з копії. Наявні записи не дублюються, а для однакових залишається новіша версія.
- Якщо видалити іконку з початкового екрана, слова зникнуть. Тому спочатку збережіть копію.

## Оновлення

Після змін у файлах збільште `VERSION` у `sw.js` (наприклад, `slovnyk-v2`). Тоді телефон підхопить нову версію після одного-двох запусків.
